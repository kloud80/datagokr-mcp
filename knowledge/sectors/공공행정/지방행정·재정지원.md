# 지방행정·재정지원

## 한 줄
지자체 단위 재정·행정 지표가 중심인 부문. 대상은 **지방재정 공시 · 국고/지방보조금 · 주민등록** 셋이고, 나머지는 목록(지방공기업·출자출연 명부)만 남기고 제거했다. PK가 자치단체코드·행정동코드라 행정표준코드(`reference-codes`)와 바로 붙는 것이 강점.

## 앞 — 체인
- **보조금**: 기획예산처 국고보조금 정보 API(15097584) → 국고보조금 집행·보조사업 현황 → 보조사업자 정보공시 대상 → 공모사업 상세 / 지방보조금관리시스템 데이터(경상남도 지방보조금_보조사업·집행내역·취득재산, 당진시 지방보조금통합관리시스템). "내가 받을 수 있는 보조금"은 창업·농업·복지·문화 전 영역 상시 수요이고 모델이 모르는 원장
- **주민등록**: 행정동·법정동별(통반 단위) 인구·세대·성연령·1인세대·평균연령·인구증감 API(15108065, 15108071, 15108072 …) + 월별 파일(15097972 등, 포털 다운로드 최상위권). 행정동 개편 시 코드가 바뀌므로 **행정구역 변경 이력과 함께** 써야 한다
- **지방재정**: 지방재정365 API 100여 개. 지표(재정자립도·자주도·채무비율)는 모델이 알지만 **세부사업별 세출현황(15059434)**·세입세출 예산·결산은 원장 — 도시에는 세부사업 API 중심, 지표는 부록

## 이관
- 주민등록 35건(국가통계·일반행정에서, `registry-to-local`), 보조금 27건(재정금융·정부자원관리 등에서, `subsidy-to-local`). 한국재정정보원 "국고보조금 추이"(국가 재정통계)는 재정금융에 남김

## 제외 (`local-admin-minor`, 801건)
지방의회(의회별 파일, 표준 코드 없음), 지자체 개별 파일(행정구역·마을·인구현황·계약대장·공유재산·통계연보 등), 행안부 잡다한 통계·안내(자원봉사, 자연재해 복구비, 자치법규 매뉴얼 등), 한국지역정보개발원 자체 자료(우수사례·동향·채용·입찰), 포항시 방문 추이 API 등

## 주의
- 지방재정365·국고보조금 API의 키 발급 경로(포털 경유인지 lofin.mois.go.kr·e나라도움 자체인지)는 Phase 2에서 확인 → `key_issuers.yaml` 갱신
- 주민등록 인구는 익월 초 갱신 — 공개 지연이 짧아 시의성 가치가 있다 (Phase 2 `event_to_publish_lag`로 확인)
