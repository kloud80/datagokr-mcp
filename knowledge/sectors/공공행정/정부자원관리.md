# 정부자원관리

## 한 줄
정부가 가진 자원(조직·인력·재산·물품·정보)을 관리하는 내부 업무. 국민 대상 서비스는 적지만 **전체 시스템의 조인 키 원장(행정표준코드)**과 **PNU 체인(국유·공유재산)**이 있어, 다른 부문보다 먼저 확정하고 목록 전체를 보관한다.

## reference-codes — 시스템 공통 마스터
- 대표: 행정표준코드_법정동코드 API(15077871), 기관코드 API(15077870), 전체코드 다운로드(15092039), 건축물용도·직종·직급 등 코드 파일
- **모든 부문 도시에의 "조인 키" 섹션이 참조하는 공통 노드** → Phase 3에서 가장 먼저 쓰는 도시에
- 원래 일반행정에 흩어져 있던 것을 이관(`govres-reference-codes`)
- 공백: 도로명주소 마스터(주소 DB·주소검색 API)는 과학기술-우정·일반행정에 있음 — 같은 성격이라 다음 검토 때 이관 여부 결정

## state-property — PNU 체인
- 캠코 온비드 API 60건을 재정금융에서 이관(`kamco-state-property`). 체납국세·국가연체채권 위탁징수 API는 재정금융에 남김
- 체인: 국유재산 현황·국유일반재산 입찰대상(15126370) → 차세대 온비드 공고목록·상세(15157216, 15157218) → 물건목록·상세(부동산 15157207·15157247, 동산·차량) → 입찰정보·결과(15157251, 15157252, 15157254) / 지자체 공유재산 대장(파일, 지자체별)
- 대중 수요: 국유재산 매각·대부, 압류재산 공매는 경매 다음가는 부동산 취득 채널 → PNU로 실거래·공시가·건축물대장과 조인, 빅밸류 AVM 도메인 직결

## portal-meta — 시스템 자체 문서
목록개방현황(15062804)·목록 메타정보(15121937)·제공 표준(15156444)은 이 시스템의 원재료. 도시에는 만들되 **전략 추천 대상이 아님**.

## 보류
- `civil-service`: 인사혁신처가 낸 것이 인사통계(파일 링크)뿐 — 나라일터 채용공고·시험 일정 API가 없어 원장 후보 없음 → 뒤로 갈 가능성 큼
- `open-facilities`: 행안부 공공개방자원(공유누리) API 12개는 외부 링크, 시설 단위 원장(주차장·회의실·체육시설) — 생활 수요는 있으나 연계 키 미확인 → Phase 2에서 컬럼 확인 후 결정
