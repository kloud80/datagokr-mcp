# 국정운영

## 한 줄
BRM 정책영역 하나에 선거·지방의회·관보·대통령기록·정책자료가 섞여 있어 세부 부문으로 나눈다. 실질 심층 대상은 **선거** 하나이고 나머지는 문서·목록·통계.

## 공백 (포털에 데이터 없음, 2026-07-31 전수 검색)
- 정치자금(`political-finance`): 정치자금법 회계보고·후원회·고액후원자 — 선관위 정치자금 공개 시스템은 포털 밖
- 규제(`regulation`): 국무조정실 규제정보포털 등록규제 API 없음 (지자체 규제개혁위원회 현황 파일, 군산시 규제정보포털 API만 존재)
- 감사·공직윤리(`audit-ethics`): 감사원 감사결과 없음. 공직자 재산공개는 관보 API로 `gazette-notice`에 있음

## 선거 (앞)
- 체인: 코드정보(15000897: 선거·정당·선거구) → 선거일정 → 후보자(15000908)·후보자 통합검색(15140045) → 선거공약(15040587)·정당정책(15040588) → 투표소(15000836)·사전투표(15040586)·개표소(15040584) → 투·개표(15000900) → 당선인(15000864). 키: sgId + huboid + 행정구역코드
- 대중 수요: 선거 직전·직후 폭발(후보·공약 비교, 우리 동네 투표소, 개표, 지역별 득표). 읍면동 득표율은 **행정구역코드로 인구·주택·상권과 조인** → 빅밸류 공간 데이터와 연결
- 뒤로: 개표결과 파일(회차별)·투표율 분석·유권자 의식조사(국가통계에서 이관 22건) — 원장(투·개표 API)에서 파생 가능한 집계
- **주기 예외**: 선거는 이벤트 때 생성되고 확정 후 불변 → freshness를 주기·경과일로 재지 않는다. 마지막 이벤트(2026-06-03 제9회 지방선거) 이후 수정 1.0, 아니면 0.7
