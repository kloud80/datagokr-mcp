# 포털 AI 검색과의 비교 — 1천 문항 (2026-10-08)

공공데이터포털 [AI 검색](https://www.data.go.kr/tcs/dss/aiAssistant.do)과 우리 서비스(채팅, 멀티헤드 전략)를 같은 질문 1,000개로 비교했다.
결과 보고서: **`report.html`** (단일 파일, 브라우저로 열기 — 분야·유형별 표, 발견한 점, 질문 1,000개 탐색).

| 단계 | 파일 |
|---|---|
| 질문 1,000개 (Opus, 16개 분야 + 분야 넘나듦 · 5가지 유형 · 어려운 질문 78) | `gen_questions.py` → `questions.yaml` |
| 포털 답 (화면이 부르는 API 순서 그대로, 동시 3) | `run_portal.py` → `portal/k*.json` |
| 우리 답 (지금 쓰는 채팅) | `run_ours.py` → `ours/k*.json` |
| 판정 (Opus — 데이터 관련성 0~2 · 답 A/B 1~5, 2026-10-07 45문항과 같은 지침) | `judge.py` → `judge/k*.json` |
| 집계·보고서 (발견한 점은 `notes.json`) | `report.py` + `report_template.html` → `report.json` · `report.html` |

## 결과

| | 우리 | 포털 |
|---|---|---|
| 답 전체 승 | **980** | 20 |
| 상위 5 중 핵심(2점) | **42%** | 29% |
| 상위 5 중 무관(0점) | **9%** | 28% |
| 관련성 · 측면 포괄 · 바로 실행 · 정직성 (1~5) | 4.37 · 4.08 · 4.35 · 4.71 | 2.82 · 2.35 · 1.62 · 2.10 |
| 질문당 평균 시간 | 21.3초 | 23.9초 |

- 질문별로 핵심 데이터를 더 많이 낸 쪽: 우리 453 · 포털 137 · 같음 410.
- 진 20문항의 절반 이상은 **전국·통합 데이터 한 장**(공공기관 신규채용현황 370개 기관, NTIS 과제·성과, KIPRIS 해외특허 등)을 놓친 경우, 4문항은 지자체가 직접 올린 지역 파일을 놓친 경우.
- 이긴 답에도 약점: 인용이 평균 7.8개로 많고(여섯 번째부터 핵심 20% 미만), '선언된 조인' 같은 내부 용어가 790개 답에 나오고, 평균 22줄로 길다.
- 포털은 52문항에 답을 거부(43개가 공공데이터로 답하기 어려운 질문). 그런 78문항에서 우리는 전승 — 없다고 말하고 대체 데이터를 제시.

**주의** — 질문 생성·판정 모두 LLM이라 편향이 있을 수 있다(긴 구조화 답 선호, 같은 회사 모델). 승패보다 데이터 정밀도와 진 문항의 이유가 더 믿을 만한 신호다. 포털 답은 1회 수집본.
