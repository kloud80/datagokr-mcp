## 1. 구글 서치 콘솔 (필수)

1. https://search.google.com/search-console → 속성 추가 → **URL 접두어** `https://labs.ai.bigvalue.co.kr/`
   - 도메인 전체(`bigvalue.co.kr`)를 관리할 수 있으면 **도메인** 속성 + DNS TXT 레코드가 더 좋습니다(하위 도메인 전부 포함).
2. 확인 방법 **HTML 태그** 선택 → `<meta name="google-site-verification" content="XXXX">`의 **content 값(XXXX)만** 저에게 주세요.
   - 제가 서버 `.env`의 `PDS_GOOGLE_SITE_VERIFICATION`에 넣고 다시 띄우면 첫 화면과 `/data` 페이지에 태그가 들어갑니다. 그다음 "확인"을 누르시면 됩니다.
   - 직접 넣으셔도 됩니다: `.env`에 `PDS_GOOGLE_SITE_VERIFICATION=XXXX` → 서버 재시작.
3. 확인되면 **Sitemaps** 메뉴에 `sitemap.xml` 제출.
4. **URL 검사**에 `https://labs.ai.bigvalue.co.kr/data/` 넣고 "색인 생성 요청" (목차부터 따라 들어가게).
5. 2~4주 뒤 **실적 → 검색어** 를 CSV로 내보내 주시면(또는 저에게 사용자 권한 추가), 페이지가 없는 검색어를 롱테일 질문으로 만들어 2차 페이지를 만듭니다.

## 2. 네이버 서치어드바이저 (필수 — 국내 검색)

1. https://searchadvisor.naver.com → 웹마스터 도구 → 사이트 등록 `https://labs.ai.bigvalue.co.kr`
2. 소유 확인 **HTML 태그** → `<meta name="naver-site-verification" content="YYYY">`의 **content 값(YYYY)** 을 저에게 주세요 (`.env`의 `PDS_NAVER_SITE_VERIFICATION`).
3. 요청 → **사이트맵 제출** `https://labs.ai.bigvalue.co.kr/sitemap.xml`
   - 네이버가 사이트맵 색인 파일을 못 읽으면 하위 파일을 각각 넣으세요: `/data/sitemap-hubs.xml`, `/data/sitemap-strategies.xml`, `/data/sitemap-datasets-1.xml`
4. 요청 → **RSS 제출** `https://labs.ai.bigvalue.co.kr/data/rss.xml`
5. 요청 → **웹 페이지 수집** 에 `/data/` 와 분야 허브 몇 개 (`/data/t/공공행정` 등) 요청.
6. 검증 → **robots.txt** 에서 수집 허용 확인.

## 5. 프록시·방화벽 확인 (필수 — 한 번만)

공개 주소 앞의 리버스 프록시(또는 CDN·WAF)가 아래를 막지 않는지 확인해 주세요.

- 경로: `/data/*`, `/sitemap.xml`, `/robots.txt`, `/llms.txt`, `/{IndexNow 키}.txt` — 지금 서버는 모두 200을 줍니다.
- 크롤러 User-Agent: `Googlebot`, `Yeti`(네이버), `Bingbot`, `Daumoa`, `GPTBot`, `OAI-SearchBot`, `ChatGPT-User`, `ClaudeBot`, `Claude-User`, `PerplexityBot`, `Google-Extended`
  — 봇 차단 규칙이 있으면 허용 목록에 넣어 주세요. AI 노출(GEO)은 이 봇들이 페이지를 읽을 수 있어야 시작됩니다.
- 프록시가 `X-Forwarded-For`를 붙이는지(이미 설정됨)와 `Host` 헤더를 그대로 넘기는지.

## 7. 결정해 주실 것

1. **포털 AI 비교 문구 공개** — 전략 페이지마다 "공공데이터포털 AI 검색과 비교"(핵심 데이터 수·점수·포털 답에 없던 것)를 넣었습니다.
   깎아내리는 표현 없이 판정 근거만 적었지만, 대외 관계상 빼거나 순화하길 원하시면 말씀해 주세요 (한 줄 설정으로 끌 수 있게 만들겠습니다).
2. **사용자 실제 질문 활용** — 원문은 공개하지 않고, 주제만 뽑아 일반화한 질문으로 페이지를 만드는 것(2차)을 해도 될지.
3. **분야 확대 순서** — 1차는 공공행정 롱테일 + 전 분야 비교 사례. 2차로 넓힐 분야(예: 국토·부동산 → 교통 → 보건)를 정해 주세요.
4. **GA4** — `/data` 페이지 방문도 GA4로 볼지. 보려면 웹 스트림 측정 ID(`G-…`)를 주세요 (`PDS_GA4_WEB_ID`, 없으면 기존 `GA4_MEASUREMENT_ID`를 씁니다).

## 9. 운영 명령 (참고)

```bash
python -X utf8 -m pds.seo.run_questions admin_1      # 질문 파일의 답 받기 (pds/seo/questions/*.yaml → seo/answers)
python -m pds.seo.build                              # 페이지 재료 다시 만들기 (seo/strategies.json) → 서버 재시작
python -m pds.seo.indexnow                           # 새 주소만 IndexNow로 알리기 (--all 전부, --dry 수만 보기)
```
